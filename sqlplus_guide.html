1 What is SQL*Plus?

SQL*Plus is Oracle's official command-line tool. It lets you type SQL and PL/SQL commands directly and get immediate results — like a direct window into your Oracle database. It comes pre-installed with Oracle XE.

  • Location on your PC: C:\oraclexe\app\oracle\product\11.2.0\server\bin\sqlplus.exe
  • Or just type sqlplus in CMD / PowerShell (if Oracle is on your PATH)
💡 When to use SQL*Plus vs PHP SQL*Plus = direct database work (create tables, test queries, see data). PHP = build the web app. For a lab demo, SQL*Plus is what you'd use to show your teacher the raw Oracle queries.

4 Basic SQL Commands (Run These in SQL*Plus)

🔍 SELECT — Read Data

SQL> SELECT * FROM Customers;

CUSTOMER_ID NAME                 EMAIL
----------- -------------------- -------------------------
          1 Alice Green          alice@example.com
          2 Bob Brown            bob@example.com
          3 Carol White          carol@example.com

-- Select specific columns
SQL> SELECT customer_id, name, email FROM Customers;

-- With WHERE condition
SQL> SELECT * FROM Customers WHERE name = 'Alice Green';

-- Order results
SQL> SELECT * FROM Customers ORDER BY name ASC;

-- Limit rows (Oracle syntax)
SQL> SELECT * FROM Customers FETCH FIRST 3 ROWS ONLY;

-- Count rows
SQL> SELECT COUNT(*) FROM Customers;
  COUNT(*)
----------
         6

➕ INSERT — Add New Row

-- The trigger automatically assigns the ID (no need to specify customer_id)
SQL> INSERT INTO Customers (name, email, phone, address, preferences)
  2  VALUES ('John Doe', 'john@example.com', '999-111-2222', '10 Oak St', 'vegan');
1 row created.

SQL> COMMIT;   -- ← IMPORTANT! Must COMMIT to save permanently in Oracle
Commit complete.

✏️ UPDATE — Edit Existing Row

SQL> UPDATE Customers
  2  SET email = 'newalice@example.com', phone = '111-999-8888'
  3  WHERE customer_id = 1;
1 row updated.

SQL> COMMIT;
Commit complete.

🗑️ DELETE — Remove a Row

SQL> DELETE FROM Customers WHERE customer_id = 7;
1 row deleted.

SQL> COMMIT;
Commit complete.

-- Delete ALL rows (but keep table structure)
SQL> DELETE FROM Customers;
SQL> COMMIT;
⚠️ Always COMMIT after INSERT / UPDATE / DELETE in Oracle! Unlike MySQL which auto-commits, Oracle requires you to explicitly type COMMIT; to save changes. If you type ROLLBACK; instead, all changes since last commit are undone.
5 GrocerCart — Specific Queries for Your Tables

View All Customers with Their Total Spending

SQL> SELECT c.customer_id, c.name, c.email,
  2         COUNT(o.order_id) AS total_orders,
  3         NVL(SUM(o.total_amount), 0) AS total_spent
  4  FROM Customers c
  5  LEFT JOIN Orders o ON c.customer_id = o.customer_id
  6  GROUP BY c.customer_id, c.name, c.email
  7  ORDER BY total_spent DESC;
-- (terminate multi-line query with semicolon on last line)

View Products with Vendor Name (INNER JOIN)

SQL> SELECT p.product_id, p.name, p.price, v.vendor_name, p.category
  2  FROM Products p
  3  INNER JOIN Vendors v ON p.vendor_id = v.vendor_id
  4  ORDER BY p.price DESC;

View Full Order Details (3-Table JOIN)

SQL> SELECT o.order_id, c.name AS customer, p.name AS product,
  2         od.quantity, od.subtotal, o.status
  3  FROM Order_Details od
  4  INNER JOIN Orders o ON od.order_id = o.order_id
  5  INNER JOIN Customers c ON o.customer_id = c.customer_id
  6  INNER JOIN Products p ON od.product_id = p.product_id;

Check the View (CustomerOrderSummary)

SQL> SELECT * FROM CustomerOrderSummary ORDER BY total_spent DESC;

SQL> DECLARE
  2      v_vendor   VARCHAR2(150);

  5      get_product_details('Organic Apple', v_vendor, v_category);

INTERSECT — Emails in Both Customers and Vendors

SQL> SELECT email FROM Customers
  2  INTERSECT
  3  SELECT contact_email FROM Vendors;

MINUS — Customer Emails NOT in Vendors

SQL> SELECT email FROM Customers
  2  MINUS
  3  SELECT contact_email FROM Vendors;

SQL> SELECT email, 'Customer' AS type FROM Customers
  2  UNION
  3  SELECT contact_email, 'Vendor' FROM Vendors

8 Running a .sql Script File

📄 What is a .sql File?

You can write multiple SQL commands in a text file (save it as .sql), then run it all at once in SQL*Plus. This is exactly what init_db.php does, but via PHP.

Example: Create a file called C:\test.sql

-- C:\test.sql contents:
SET SERVEROUTPUT ON
SET LINESIZE 200

SELECT * FROM Customers;
SELECT * FROM Vendors;
SELECT COUNT(*) AS total_orders FROM Orders;

BEGIN
    DBMS_OUTPUT.PUT_LINE('Script complete!');
END;
/

Run It in SQL*Plus

SQL> @C:\test.sql
-- or
SQL> START C:\test.sql

Run Script Directly from CMD (without entering SQL*Plus first)

sqlplus salehin_076923/2207045@localhost/XE @C:\test.sql
9 PL/SQL Blocks in SQL*Plus
💡 How to run PL/SQL (multi-line blocks) For PL/SQL blocks (DECLARE/BEGIN/END), you must end with a / on its own line. The semicolon ; ends individual statements INSIDE the block, but / tells SQL*Plus to execute the entire block.

Anonymous PL/SQL Block

SQL> DECLARE
  2      v_count NUMBER;
  3  BEGIN
  4      SELECT COUNT(*) INTO v_count FROM Customers;
  5      DBMS_OUTPUT.PUT_LINE('Total customers: ' || v_count);
  6  END;
  7  /    ← this / runs the block
Total customers: 6

PL/SQL procedure successfully completed.

SQL> CREATE OR REPLACE TRIGGER trg_check_price
  2  BEFORE INSERT OR UPDATE OF price ON Products
  3  FOR EACH ROW

  7      END IF;
  8  END;

11 Common Errors & Fixes
ORA-01017: invalid username/password
logon denied
Fix: Wrong username or password. Check: salehin_076923 / 2207045
ORA-12541: TNS:no listener
Fix: Oracle listener is not running. Start OracleXETNSListener service in Windows Services.
ORA-00942: table or view does not exist
Fix: Table doesn't exist yet. Run init_db.php first or check spelling.
ORA-02291: integrity constraint
violated - parent key not found
Fix: Foreign key violation. Make sure the referenced row exists in the parent table first.
SP2-0042: unknown command ...
rest of line ignored
Fix: You typed a SQL*Plus command incorrectly, or used MySQL syntax. Check the command spelling.
ORA-04091: table is mutating
Fix: Trigger reads its own table. Use PRAGMA AUTONOMOUS_TRANSACTION (already fixed in our project).
